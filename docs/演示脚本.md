# 3 分钟内操作视频脚本

**0:00—0:20｜开场** 进入首页，介绍「工位情绪回收站」：把小烦恼交给加班幽灵处理。

**0:20—0:50｜输入** 点击「改了 8 版的 PPT」示例，再手动修改几字，展示可自行输入。

**0:50—1:15｜选择** 依次点开三种处理方式，最后选「发射到外太空」。

**1:15—1:45｜回收** 点击「开始情绪回收」，展示动画和幽灵反馈。

**1:45—2:15｜凭证** 展示凭证里的烦恼、处理方式、幽灵批注，点击「保存凭证图片」。

**2:15—2:45｜再来一次** 点击「再回收一个」，输入另一个烦恼，选择不同处理方式快速演示。

**2:45—3:00｜结尾** 总结：核心流程可运行，手机和电脑都能体验；输入只在本地处理。

录制前可将浏览器缩放调到适合的比例；视频中不要输入真实敏感信息。
