# 产品介绍｜工位情绪回收站

## 一句话介绍

把今天的工位小烦恼交给一只加班幽灵，换一张「工位存活凭证」。

## 参赛方向

脑洞趣味｜好玩，就是生产力。

## 为什么做

日常工作里常有一些不值得大动干戈、却会短暂影响心情的小事。我们想把「说出来」变成一个轻松的互动仪式：写下烦恼，选择一种荒诞的处理方式，看它从屏幕上消失。

## 核心玩法

1. 输入一件今天的烦恼，或点击示例快速填入。
2. 在「碎成像素」「发射到外太空」「封进下班盒」中选一种处理方式。
3. 点击回收，看加班幽灵完成处理，并获得带有原文、处理方式和幽灵批注的凭证。
4. 保存凭证图片，发给朋友或同事。

## 亮点

- 复古像素游戏风格的工位场景和幽灵反馈。
- 三种处理方式对应不同动画和轻松吐槽文案。
- 手机和电脑都能使用，无需注册。
- 输入内容只在当前页面处理，不上传、不保存。

## 使用形式

响应式网页 H5。原生 HTML、CSS、JavaScript 实现，无需后端。

## 后续可以继续共创

增加幽灵表情、更多「烦恼回收法」、节日限定凭证和同事共创文案。
